# 조선기 | 데이터 품질과 검증 중심의 비전 AI

한성대학교 AI응용학과 재학 중입니다.
모델 점수보다 **믿을 수 있는 데이터와 정직한 평가**를 먼저 챙깁니다. 같은 대상이 학습과 시험에 섞이지 않게 나누고, 오탐은 사진으로 직접 확인하고, 한계까지 기록합니다.
요양보호사와 복지 현장 경험이 있어, 기술을 실제로 쓸 사람을 보며 만듭니다. 목표는 의료기기 AI 엔지니어입니다.

## 일하는 방식

- 도구를 쓰기 전에 문제를 심은 가짜 데이터로 도구부터 검증합니다.
- 한 실험에 하나만 바꾸고, 모델 선택은 검증 데이터로만, 시험 데이터는 마지막에 한 번만 봅니다.
- 숫자가 나쁘면 사진을 직접 보고 원인을 평가 기준·라벨·모델로 나눕니다.
